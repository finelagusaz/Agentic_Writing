# 旧エージェント役割定義（第一部システム）

第一部（2026年2月完結）で使用された editor / manager 構成の役割定義。
2026年7月23日、無参照であることを確認して `agents/` から移設した。

| ファイル | 旧役割 | 廃止の経緯 |
|---------|--------|-----------|
| `editor.md` | 編集エージェント。方針策定（current-direction.md）とフィードバック統合を担当 | アーク駆動化（第二部システム）でエピソードブリーフ生成がオーケストレーター直接実行になり廃止。`/edit-story` も専用エージェントを使わない |
| `manager.md` | 担当編集者。ドラフトの品質評価と合否判定を担当 | arc-reviewer（役割タグ準拠評価）に置換 |

第一部→第二部のシステム転換の全体経緯は `archive/retrospective-vol1-2026-02/` を参照。
