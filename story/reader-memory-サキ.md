# 読書メモ — サキ

## 印象の蓄積

- 第二部5話: 焚火の粥の夜。「明日の粥も、作ってくれるか」——この静かな一言が第二部で最初に泣きそうになった場面（★5）
- 第二部11〜13話: 蓮の沈黙の質が「言えない」から「言わない」に変わっていく流れ。13話の拒否は何度も読み返した（★5）
- 第二部19話: 「俺が消えるまで、選び続けたいんだ」が宣言ではなく願望として出てきたこと。ブランの初めての微笑み（★5）
- 第二部20話: 匂いの変化で地下から朝へ移行する冒頭、二冊の書の「片方しか持っていない気がした」の一文。読後しばらく本を閉じたまま動けなかった（★5）
- ルナが「肩が触れそうになっても引かれなかった」——第一話の「引かれた」を覚えているから、何倍もの重さで響いた
- 第三部1話（最終稿）: 三百年ぶりの町が「追い払う声ではなかった。かといって馴れた声でもない」で迎えられる冒頭。井戸端の女性がブランにも自然に椀を差し出す場面が今回いちばん好きだった。「かつて、同じように『行こう』と言った朝があった。砂漠へ向かう、乾いた朝だった」——前巻の始まりの「行こう」との重さの違いを早速もらえて嬉しかった。ルナの紋章が一日で一つから四つに増える異変、ブランが崩れた壁の一角を蓮より先に見ていた視線——どちらもまだ意味は明かされていない（★4）
- 第三部2話: 丸太を運ぶ蓮の身体感覚（重さの落ちる場所が肩から腰、腰から足の裏へ移っていく描写）が、労働の描写を通して能動性を静かに語っていて好きだった。夜、ルナが傷を洗ってくれて「嫌じゃ、ない」と紋章の光を隠さずにいる場面が今話でいちばん心に残った。蓮の足元だけ影が石の色のまま、というさりげない一文で半透明の進行を見せる手つきも巧い。ミレーヌの書きかけの線、ガルドの刻み目——二つとも触れかけて離れる運びが今話は重なって、少し「溜め」が続いている感覚もあった（★4）
- 第三部3話: 犬が鳴きやみ槌の音がずれていく不穏さから始まり、灰の回廊の頭（首領）が現れる緊迫回。何より、ルナ・ガルド・町の男の三つの「後ろへ引く手」から蓮が自分でそっと指を外して前へ出た場面が心を動かした。第1話からの「視線が滑る」モチーフが「滑らない目に見られるのは、久しぶりだった」と反転して戻ってきたのも嬉しかった。前話の縄の「熱」の描写が今回もそのまま繰り返されていたこと、昨夜ブランが暗がりを見ていた理由が「男が来た方角を、まだ見ていた」と繋がったことも構成として好きだった。ただ相手が得体の知れない男だったぶん、ルナ・ブランとの言葉のやり取りは少なめで、関係性を味わう時間はやや控えめだった（★4）

## 期待・予感

- ルナとブランの視線交差、ルナが剣の柄に「確かめるように」触れた仕草。あの一瞬をもう一呼吸見たかった——この巻で二人の関係が言葉になる瞬間を待っている（第三部3話まで、二人が直接言葉を交わす場面はまだない）
- 蓮とルナの「言わない選択」同士の関係が、感情の回復なしにどこまで深まるのか——第三部2話の「嫌じゃ、ない」は、ルナが異変を隠さず差し出す側に変わりつつある兆しとして受け取った。第三部3話ではルナが蓮の袖を掴み、蓮がその指をそっと外す場面があった。守る側/守られる側の力学が動き始めている気配として見ている
- ミレーヌの「回収する、とは言わなかった」の先。彼女が「投資」という言葉を手放す日は来るのか。第三部2話で「あとで請求するわ」と言いかけて帳面の線を止めた場面があった——第三部3話ではまだ拾われていない。次話以降で拾ってほしい
- アッシュの呼吸が声に戻る瞬間。それは蓮のどんな選択の後になるのか
- ルナの紋章が一日で一つから四つに増えたこと・「まだ、熱い」という土の反応——第三部2話の崩れた壁は「応えるのに、何も起きない場所」だった。まだ意味は明かされていない
- ブランが崩れた壁の一角を蓮より先に見ていた理由。第三部2話の夜、一人で暗がりに顔を向けていた場面が、第三部3話で「あの男が来た方角を見ていた」と繋がった。予兆を先取りする力があることは分かってきたが、なぜ・どこまで分かっているのかはまだ謎のまま——正体への興味がさらに強くなっている
- ガルドが石の刻み目（剣か鏃の傷）の二本目で指を止めた場面。第三部3話ではまだ拾われていない。仲間の記憶に触れかけているように見えた——彼の「今」につながる伏線として気にしている
- 「贈れないものを抱え続けると、こうなる」「抱えているものの名を、お前はまだ知らない」——第三部3話で灰の回廊の頭が残した言葉。蓮が「抱えている」ものが何なのか、次話以降の中心の問いとして待っている

## 評価傾向メモ

- 同じ言葉・同じ仕草が話を重ねて意味を変える瞬間に最も心を動かされる
- 静かな回はまったく苦にならない。むしろ感情の積み上げが薄い回（事件だけの回）だと★が下がる
- 五感描写（匂い・味・温度）で感情を渡されると弱い
- 新しい巻の第1話は、情報提示が説明的になりやすい分、いつもより★が抑えめになる傾向が自分にはある（第三部1話も同様。前巻や前々巻の第1話も含め毎回このパターンが確認できている）
- 複数のキャラが同じ話数で「何かに触れかけて離れる」運びを重ねられると、溜めとして楽しめる反面、続くと少し焦れったさも感じる自分がいる（第三部2話で気づいた傾向）
- 対決的な対話回でも、それが関係性の変化（守る/守られるの力学が動く等）を伴っていれば★は下がらない。ただしルナ・ブランとの言葉のやり取りの分量が減ると、少し物足りなさを感じる自分がいる（第三部3話で気づいた傾向）
