# 読書メモ — ユウキ

## 印象の蓄積

- 第二部10話: 記憶を操る奴との初接触。久々に動いた回で★4
- 第二部13話: 「何を覚えるかは、自分が決める」——蓮が自分で動いた。この作品で一番好きな系統の回（★4）
- 第二部14話: 余韻回。正直ダレた（★2）。静かな回が続くとしんどい
- 第二部18話: ガルドが無言で体を壁にした瞬間「お、来た」ってなった。ラストの「砂の一粒が動いた。風はなかった」は今シリーズで一番強い引きだった
- 第二部19話: 「いらない」の一言と「俺が消えるまで、選び続けたいんだ」。バトルゼロなのに読んだ甲斐があった（★4）。蓮の能動性が全部乗った回
- 第二部20話: 綺麗にまとまってたけど、第二部ラストとしては引きが弱くてモヤっとした（★3）。次巻の種がもう一つ欲しかった
- 第三部1話: ヴェルディア帰還、復興の町の描写が前半長めでスロースタート（★3）。ルナの紋章反応が「昨日は一つ、今日は四つ」って数字で来た異変と、蓮が迷いを声にする前に「見に行こう」って即断したのは良かった。「行こう」が第一部の砂漠へ向かう朝の台詞と重なる書き方も効いてる。新章の引きとしては「拍が速くなった」でまあまあ、砂の一粒ほどの爆発力はなし
- 第三部2話: 前回の「拍が速くなる」引きを、壁のシーンで「応えて、それだけだった」とあっさり流して丸太運びの日常回に転換（★3）。蓮が誰にも頼まれず丸太に手を伸ばす能動性、体が先に持ち方を覚えていく描写は好きだったけど、事件らしい事件がなくテンポは重め。ガルドの石の刻み目（二本目で指が止まる）とブランの夜の暗闇凝視で、次への引っかかりはギリギリ繋いでる

## 期待・予感

- ブランの「私もかつて、選ぶ前のあなただった」——正体は何なんだ。早く回収してほしい
- ルナとブランの無言の視線交換。ルナが剣の柄に触れたのは何のフラグ？
- 蓮の半透明、「消えるまで選び続けたい」って言っちゃったけど本当に消えていくのか
- 回廊の首領とセルジュの「ある一人」、二巻ずっと放置されてる。そろそろ動いてくれ
- ルナの紋章反応が1日で4箇所に急増した理由——第三部2話で壁に触れたけど「応えて、それだけ」で終わり、正体はまだ持ち越し。次こそ何か見せてほしい
- ブランが「蓮より先にその場所を見ていた」——何か知ってる顔してた。ここも気になる
- 新規: ガルドが見つけた石の刻み目（剣の柄か鏃でつけたような三本の傷）。二本目で指が止まって何も言わなかった。ヴェルディア関連の過去の記憶か、仲間の誰かに繋がる伏線の匂い
- 新規: ミレーヌが復興の男に「何が欲しいんだ」と聞かれて、帳面の線が止まり、口を開いて閉じた。何か言いかけて呑み込んだ感じがした。触れられたくない部分がありそう
- 新規: ブランが夜、崩れた壁の外側の暗がりをじっと見ていた。何を見てる/待ってるのか

## 評価傾向メモ

- 蓮が「自分で選んで動く」回に★4を出している（10話・13話・19話）。バトルの有無より能動性
- 静か系の回が3話続くと体感がきつくなり★が下がる（14話、17〜18話）
- 引きが強いと同じ静かさでも許せる（18話の砂の一粒）
- 「余韻回だから静か」は理解してるが、読み手の体はそれとは別に正直に止まる
- 新章1話目は世界観再導入・日常描写に尺を使いがちで、自分は体感でテンポが重く感じやすい（第三部1話で実際にスロースタートと感じた）。ただし異変の提示（数字で来る紋章反応）と主人公の即断があれば持ち直せる、というのも今回で確認できた
- 前話で強めに引かれた謎を次話冒頭であっさり流されると、勢いが途切れたように感じてテンポ評価が下がりやすい（第三部2話で確認）。日常回でも、体の描写や小さい謎の配置（今回のガルドの刻み目・ミレーヌの言い淀み）があれば★2までは落ちず★3で踏みとどまる、というのも今回分かった
