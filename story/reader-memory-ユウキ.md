# 読書メモ — ユウキ

## 印象の蓄積

- 第二部10話: 記憶を操る奴との初接触。久々に動いた回で★4
- 第二部13話: 「何を覚えるかは、自分が決める」——蓮が自分で動いた。この作品で一番好きな系統の回（★4）
- 第二部14話: 余韻回。正直ダレた（★2）。静かな回が続くとしんどい
- 第二部18話: ガルドが無言で体を壁にした瞬間「お、来た」ってなった。ラストの「砂の一粒が動いた。風はなかった」は当時、今シリーズで一番強い引きだった
- 第二部19話: 「いらない」の一言と「俺が消えるまで、選び続けたいんだ」。バトルゼロなのに読んだ甲斐があった（★4）。蓮の能動性が全部乗った回
- 第二部20話: 綺麗にまとまってたけど、第二部ラストとしては引きが弱くてモヤっとした（★3）。次巻の種がもう一つ欲しかった
- 第三部1話: ヴェルディア帰還、復興の町の描写が前半長めでスロースタート（★3）。ルナの紋章反応が「昨日は一つ、今日は四つ」って数字で来た異変と、蓮が迷いを声にする前に「見に行こう」って即断したのは良かった。新章の引きとしては「拍が速くなった」でまあまあ、砂の一粒ほどの爆発力はなし
- 第三部2話: 前回の「拍が速くなる」引きを、壁のシーンで「応えて、それだけだった」とあっさり流して丸太運びの日常回に転換（★3）。蓮が誰にも頼まれず丸太に手を伸ばす能動性は好きだったけど、事件らしい事件がなくテンポは重め。ガルドの石の刻み目とブランの夜の暗闇凝視で、次への引っかかりはギリギリ繋いでる
- 第三部3話: 犬が鳴きやむ→槌が止まる→釣瓶が止まる、の連鎖だけで町中が凍りつく緊迫感。バトルゼロなのに一気に手が止まらなくなった（★4）。灰の回廊の頭が単身で登場、蓮が三人分の「引く手」を振り切って自分から「あんたは、何を抱えてる」って前に出たのが熱かった。ただし首領は結局何もせず帰っていって実害ゼロ、「三百年、誰も聞かなかった」で指が動いたのに開かずじまいだったのは肩透かし。ラストの「抱えているものの名を、お前はまだ知らない」は18話の砂の一粒を更新する、今シリーズで一番刺さる引き

## 期待・予感

- ブランの「私もかつて、選ぶ前のあなただった」——正体は何なんだ。早く回収してほしい
- ルナとブランの無言の視線交換。ルナが剣の柄に触れたのは何のフラグ？
- 蓮の半透明——ルナしか知らなかったのが、第三部3話で首領に「腕の縁がぶれてる、石と混ざりかけてる」って他人から名指しされた。もう隠せなくなってきてる。悪化の方向で来てるのが怖い
- 回廊の首領——第三部3話でついに直接登場。「贈れないものを抱え続けると、こうなる」「抱えているものの名を、お前はまだ知らない」って蓮に投げっぱなしで帰っていった。正体も「抱えているもの」の中身もまだ。せっかく動いたんだからもっと引き出してほしい
- セルジュの「ある一人」——首領とは別に、こっちはまだ完全放置。そろそろ触れてくれ
- ルナの紋章反応が1日で4箇所に急増した理由——第三部2話で壁に触れたけど「応えて、それだけ」で正体は持ち越し中
- ブランが「蓮より先にその場所を見ていた」——何か知ってる顔してた。ここも気になる
- ガルドが見つけた石の刻み目（二本目で指が止まった）。ヴェルディア関連の過去の記憶か、仲間の誰かに繋がる伏線の匂い
- ミレーヌが「何が欲しいんだ」と聞かれて帳面の線が止まり、何か言いかけて呑み込んだ。触れられたくない部分がありそう
- ブランが夜、崩れた壁の外側の暗がりをじっと見ていた件——第三部3話で深まった。首領は西の街道から来て、ブランは男自身じゃなく「男が来た方角」をずっと見てた。ただの偶然には見えない

## 評価傾向メモ

- 蓮が「自分で選んで動く」回に★4を出している（10話・13話・19話、そして第三部3話も同じ系統）。バトルの有無より能動性
- 静か系の回が3話続くと体感がきつくなり★が下がる（14話、17〜18話）
- 引きが強いと同じ静かさでも許せる（18話の砂の一粒、第三部3話の「抱えているものの名」）
- 「余韻回だから静か」は理解してるが、読み手の体はそれとは別に正直に止まる
- 新章1話目は世界観再導入・日常描写に尺を使いがちで自分は体感でテンポが重く感じやすい。ただし異変の提示と主人公の即断があれば持ち直せる（第三部1話で確認）
- 前話で強めに引かれた謎を次話冒頭であっさり流されると勢いが途切れたように感じてテンポ評価が下がりやすい（第三部2話で確認）。ただし体の描写や小さい謎の配置があれば★2までは落ちず★3で踏みとどまる
- 新規: 中テンポの回が2話続いても、対峙（バトルじゃなくてもいい）と主人公が自分から一歩出る瞬間があれば★4まで持ち直す（第三部3話で確認）。自分は「動くこと」自体より「怖くても自分から前に出る」動作にいちばん反応してる
